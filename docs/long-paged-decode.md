### Fused packed GQA

The fused step prepares Q and K, appends the new packed KV, and runs attention and output gating on the batch stream. The split uses whole 64-token chunks, with up to 16 partials per lane and query head. It preserves the original BF16 Q and expands raw E4M3 operands exactly to BF16. QK and PV use BF16 MMA with FP32 accumulation. PV rounds the probability times the relative V scale to BF16. Range checks cover operands, scale updates, and the merge. A flagged head replays attention in FP64. The fast path can still lose precision through cancellation. See [the regression inputs and results](lessons.md#l006--fp16-operand-loss-in-split-gqa). [Fused step](https://github.com/para1lel/sglang.cpp/blob/e1735c36c701581fd559bcaaa0d5adeb8c0337ad/src/text/gqa_decode_prepare.cu#L77)<!-- prefix: "cudaError_t " --> · [Split selection](../include/sglang/text/gqa_decode_split.cuh#L50)<!-- prefix: "__host__ __d" --> · [Merge](../include/sglang/text/gqa_decode_split.cuh#L124)<!-- prefix: "__device__ i" -->

The packed route uses two shared-memory stages. Each of four warps copies and consumes its own 16-token slice of the chunk. The payload copies use 16-byte `cp.async.cg` and zero-fill tokens past the visible tail. The scale copies use 8-byte `cp.async.ca` to give each warp disjoint scale writes. [Stage count](../src/text/gqa_decode_split.cu#L18)<!-- prefix: "constexpr in" --> · [Copy ownership](../src/text/gqa_decode_split.cu#L137)<!-- prefix: "__device__ v" --> · [Payload copy](../src/text/gqa_decode_split.cu#L98)<!-- prefix: "asm volatile" --> · [Tail predicate](../src/text/gqa_decode_split.cu#L152)<!-- prefix: "const bool v" --> · [Scale copy](../src/text/gqa_decode_split.cu#L170)<!-- prefix: "asm volatile" -->

Warp zero loads BF16 query fragments and their range flags into shared memory. The same CTA barrier publishes the query and page indices. During scoring, each of the four warps reads one 32-channel query group at a time. [Page indices](../src/text/gqa_decode_split.cu#L550)<!-- prefix: "for (int ind" --> · [Query publication](../src/text/gqa_decode_split.cu#L558)<!-- prefix: "__syncthread" --> · [Query group read](../src/text/gqa_decode_split.cu#L268)<!-- prefix: "const auto w" -->

In the two-stage loop, lanes wait for their copy groups and synchronize within the warp before they refill one stage and consume the other. All lanes drain their copies and synchronize across the CTA before they reuse shared memory for the merge. A final CTA barrier publishes the warp results before the block writes split partials. The former operator was removed when grouped split GQA gained automatic [long draft dispatch](native-model-info.md#draft-attention). ## Constraints and failure behavior

The legacy wide forward used row dispatch for out-of-window lanes. Exact policy, media, MTP, and prefill rows used separate routes. The old long primitive accepted one through 32 descriptors. [Historical eligibility](https://github.com/para1lel/sglang.cpp/blob/93648269d852e0fee78f7af4d1c3ffe4897aa361/src/decoder_batch.cpp#L660)<!-- prefix: "const bool p" --> · [Former primitive](https://github.com/para1lel/sglang.cpp/blob/93648269d852e0fee78f7af4d1c3ffe4897aa361/src/mxfp8_gqa.cu#L987)<!-- prefix: "cudaError_t " -->

The launcher checks the complete group before submission. An invalid count, null required pointer, unaligned scratch address, out-of-window position, or insufficient declared cache or page-table capacity returns `cudaErrorInvalidValue`. The caller supplies valid device page entries and enough scratch for each lane. The launcher stops at the first synchronous CUDA launch error. Earlier launches can still be in flight. The forward propagates the error through the batch execution path. [Validation and launch](https://github.com/para1lel/sglang.cpp/blob/93648269d852e0fee78f7af4d1c3ffe4897aa361/include/sglang/text/mxfp8_gqa_decode.cuh#L380)<!-- prefix: "cudaError_t " --> · [Cache coverage](../include/sglang/text/gqa_verify_batch.h#L55)<!-- prefix: "inline bool " --> · [Forward error](https://github.com/para1lel/sglang.cpp/blob/93648269d852e0fee78f7af4d1c3ffe4897aa361/src/decoder_forward.cpp#L630)<!-- prefix: "check(status" -->

The tensor-core split flags a query head if an input is nonfinite, a BF16 subnormal, or has magnitude above `2^30`. Visible nonfinite K or V flags all six query heads of that KV group. A nonzero decoded K or V magnitude below `2^-126` or above `2^30` also flags the group. The paired split flags nonfinite visible scores or partials and visible V scale bytes above 160. Both routes flag invalid merged maxima, mass, numerators, or BF16 results. A flagged head replays the visible tokens in order in FP64 from the original packed KV. Other heads keep their split results. [Query guard](https://github.com/para1lel/sglang.cpp/blob/93648269d852e0fee78f7af4d1c3ffe4897aa361/include/sglang/text/mxfp8_gqa_wide_tc.cuh#L200)<!-- prefix: "const bool i" --> · [KV range guard](https://github.com/para1lel/sglang.cpp/blob/93648269d852e0fee78f7af4d1c3ffe4897aa361/include/sglang/text/mxfp8_gqa_wide_tc.cuh#L64)<!-- prefix: "const bool i" --> · [Merge guard](../src/mxfp8_gqa.cu#L624)<!-- prefix: "const bool i" --> · [Head replay](../src/mxfp8_gqa.cu#L635)<!-- prefix: "__device__ _" -->

Both splits change the reduction order. The tensor-core split also rounds numerator weights to BF16. Either choice can change BF16 attention output, logits, and generated IDs, including the greedy winner in a near tie.
