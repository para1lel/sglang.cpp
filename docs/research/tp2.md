## Checkpoint to rank-local operators

Shapes use `[output,input]`. Rank `r` takes `[r·n,(r+1)·n)` along each logical axis with local length `n`. Slice output rows for column-parallel weights and input columns for row-parallel weights, before packing or transposition. | --- | --- | --- |

## LMCache rank ownership

Each rank has its own LMCache 0.5.8 daemon, socket and physical UUID. Cache identity distinguishes logical rank and world size from the UUID that owns an IPC allocation. Each rank has four MXFP8 target KV planes with `512,512,16,16` bytes per token per layer, or 16,896 bytes per token across 16 GQA layers. Pages contain 128 rows, with scales in page/head/token-within-32/token-group/channel-group order. Each GDN endpoint holds 76,992,512 bytes, including the replicated final BF16 hidden and residual rows. [Native cache contract](../prefix-cache.md#checkpoint-compatibility-and-resume)

Both ranks must restore the same exact GDN endpoint `P` and target KV through `P`. Intersect eligible endpoints and publish only after both transfers finish. Rank 0 runs the entire draft, retains the full target embedding and output head, and requires draft KV through `P−1`. Its four draft KV heads use 2,112 bytes per cached token. The reference draft split uses 1,056 bytes per rank. Count restored prompt tokens once per request. [Ranked serving](../serving/tp2.md) · [MTP](../mtp.md)
